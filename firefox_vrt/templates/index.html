Compare Firefox chrome screenshots

Paste a Firefox revision (try / autoland / mozilla-central). We fetch its mochitest-browser-screenshots CI artifacts from Taskcluster, then diff them against a baseline you pick.

The revision needs to have actually captured screenshots — most CI runs don't.

The mochitest-browser-screenshots job is a no-op unless the task was launched with the MOZSCREENSHOTS_SETS env var set. Default autoland / mozilla-central pushes finish green without capturing anything. For this tool to find PNGs, the push you paste must be one where someone explicitly opted in — typically a try push: 

./mach try fuzzy -q "mochitest-browser-screenshots" \
  --env "MOZSCREENSHOTS_SETS=Toolbars,Tabs,WindowSize,CustomTitlebar,LightweightThemes,DevTools,AppMenu,Buttons,CustomizeMode,UIDensities,Preferences"

If you paste a revision whose job ran but didn't capture, you'll see a clear "0 PNGs" failure in the debug panel.
